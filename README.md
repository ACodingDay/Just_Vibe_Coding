## 📦 项目列表

### 🎯 [valorant-tauri-app](./valorant-tauri-app/)

> Valorant 游戏进程优化工具

基于 **Tauri + Rust + Vanilla JS** 构建的 Windows 桌面应用，用于自动检测并优化 Valorant 相关进程的 CPU 亲和性与优先级，减少后台进程对游戏帧率的干扰。

| 技术栈 | 平台 | 状态 |
|--------|------|------|
| Tauri v2 + Rust + Vanilla JS | Windows | ✅ 可用 |

**核心功能：**
- 🔍 自动检测游戏相关进程运行状态
- ⚙️ 一键设置 CPU 亲和性（绑定到最后一个核心）
- 📉 将后台进程优先级降至 Idle
- 🎨 亮色 / 暗色主题切换
