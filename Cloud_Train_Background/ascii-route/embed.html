<ascii-art> 组件嵌入演示

借鉴 ascii.rest 的单标签封装架构 · 渲染核心仍是本目录的 GPU 字形 pass（未改）

<ascii-art theme="clouds"> 默认云海 · 30fps · cell 8
<ascii-art theme="ocean" mono cell="14"> 大海 · 磷屏绿 · 大字符格
options='{"theme":"ocean","speed":1.2,"asciiGamma":1.5,"asciiCell":6}'

三个实例各自独立：独立设置、独立 IntersectionObserver 离屏停绘（滚出视口即停绘省电）、独立 fps 上限。

元素填满自身盒子，宿主用 CSS 给尺寸（本页 .stage{height:42vh}）。JS 接口：el.settings / el.reboot() / el.wake() / 事件 ascii-stats·ascii-fps·ascii-intro-done。
